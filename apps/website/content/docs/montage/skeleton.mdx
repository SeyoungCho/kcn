## Installation

```npm
npx shadcn@latest add @kcn-montage/skeleton
```

## Usage

The API matches shadcn's Skeleton, with an extra `variant` prop for the shape. It fills the available width by default; set size, radius and color with `className`.

## Examples

### Variants

`text` matches a line of text, `rectangle` suits images and cards, and `circle` suits avatars.
