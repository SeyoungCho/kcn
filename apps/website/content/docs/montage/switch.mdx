## Installation

```npm
npx shadcn@latest add @kcn-montage/switch
```

## Usage

The API matches shadcn's Switch, including `size` (`default`, `sm`). Wrap it in a `<label>` with its text (or use `Field`) — otherwise give it an `aria-label`.
