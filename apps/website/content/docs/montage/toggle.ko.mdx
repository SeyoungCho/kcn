## 설치

```npm
npx shadcn@latest add @kcn-montage/toggle
```

## 사용법

API 는 shadcn 의 Toggle 과 같고, `icon` 배리언트와 `xs` 크기가 더 있어요. 글자 옆 아이콘에는 `data-icon="inline-start"` 나 `"inline-end"` 를 달아야 여백이 맞아요.

```tsx
<Toggle>
  <PlusIcon data-icon="inline-start" />
  추가
</Toggle>
```
