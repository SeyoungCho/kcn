## Installation

```npm
npx shadcn@latest add @kcn-montage/pagination
```

## Usage

The API matches shadcn's Pagination. Previous and next are icon-only arrows; mark them with `aria-disabled` on the first and last page. `PaginationCounter` and `PaginationDots` are extra parts for showing the position without page numbers.

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        1
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```
