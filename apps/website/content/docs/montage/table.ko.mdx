## 설치

```npm
npx shadcn@latest add @kcn-montage/table
```

## 사용법

API 는 shadcn 의 Table 과 같아요. 표는 둥근 테두리 안에서 따로 스크롤되고, `TableRow` 에 `interactive` 를 주면 누를 수 있는 줄이 돼요.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>주문 번호</TableHead>
      <TableHead>상품</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>LL-2481</TableCell>
      <TableCell>몬스테라 델리시오사</TableCell>
    </TableRow>
  </TableBody>
</Table>
```
