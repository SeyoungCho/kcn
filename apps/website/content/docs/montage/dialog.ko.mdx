## 설치

```npm
npx shadcn@latest add @kcn-montage/dialog
```

## 사용법

API 는 shadcn 의 Dialog 와 같아요. `DialogHeader` 와 `DialogFooter` 사이의 내용에는 여백이 알아서 붙고, 버튼 줄의 버튼은 폭을 나눠 가지니 `size="lg"` 로 넣어 주세요. 더 넓은 창이 필요하면 `w-120` 같은 폭 클래스를 주세요.
