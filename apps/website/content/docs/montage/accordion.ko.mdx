## 설치

```npm
npx shadcn@latest add @kcn-montage/accordion
```

## 사용법

API 는 shadcn 의 Accordion 과 같고, `Accordion` 에 `variant` · `size` 가 더 있어요. `multiple` 을 주지 않으면 한 항목을 펼칠 때 다른 항목은 접혀요.

```tsx
<Accordion multiple>
  <AccordionItem value="watering">
    <AccordionTrigger>물은 얼마나 자주 줘야 하나요?</AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```
