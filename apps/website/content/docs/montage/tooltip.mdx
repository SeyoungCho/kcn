## Installation

```npm
npx shadcn@latest add @kcn-montage/tooltip
```

## Usage

The API matches shadcn's Tooltip, with an extra `size` prop on `TooltipContent` and a `TooltipShortcut` part. Place one `TooltipProvider` near the root of your app; it sets the open and close delays.
