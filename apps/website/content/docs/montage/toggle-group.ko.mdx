## 설치

```npm
npx shadcn@latest add @kcn-montage/toggle-group
```

## 사용법

API 는 shadcn 의 ToggleGroup 과 같지만, 항목이 한 줄로 붙지 않고 떨어져 놓여요. 그룹에 준 `variant` · `size` 는 모든 항목에 적용돼요.

```tsx
<ToggleGroup defaultValue={["all"]}>
  <ToggleGroupItem value="all">전체</ToggleGroupItem>
  <ToggleGroupItem value="foliage">관엽식물</ToggleGroupItem>
</ToggleGroup>
```
