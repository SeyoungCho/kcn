## 설치

```npm
npx shadcn@latest add @kcn-montage/item
```

## 사용법

API 는 shadcn 의 Item 과 같아요. `<a>` · `<button>` 으로 그리면 누를 수 있는 줄이 되고, 고른 줄에는 `aria-current`, 쓸 수 없는 줄에는 `aria-disabled` 를 달아요.

```tsx
<ItemGroup>
  <Item render={<button type="button" />}>
    <ItemMedia>
      <BellIcon />
    </ItemMedia>
    <ItemContent>
      <ItemTitle>알림</ItemTitle>
      <ItemDescription>물 주기 알림, 주문 소식</ItemDescription>
    </ItemContent>
    <ItemActions>
      <ChevronRightIcon />
    </ItemActions>
  </Item>
</ItemGroup>
```
