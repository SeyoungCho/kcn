## 설치

```npm
npx shadcn@latest add @kcn-montage/badge
```

## 사용법

API 는 shadcn 의 Badge 와 같고 `color` · `size` prop 이 더 있어요. `variant` 로 바탕을 옅게 칠할지 테두리만 두를지 고르고, `color` 로 글자 · 바탕 · 테두리의 색을 한 번에 정해요.
