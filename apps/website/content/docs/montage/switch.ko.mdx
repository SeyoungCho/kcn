## 설치

```npm
npx shadcn@latest add @kcn-montage/switch
```

## 사용법

API 는 shadcn 의 Switch 와 같고, `size`(`default` · `sm`)도 있어요. 글자와 함께 `<label>` 로 감싸거나 `Field` 를 쓰고, 보이는 글자가 없으면 `aria-label` 을 달아 주세요.
