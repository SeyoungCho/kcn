## 설치

```npm
npx shadcn@latest add @kcn-montage/select
```

## 사용법

API 는 shadcn 의 Select 와 같아요. `Select` 에 `items` 를 주면 `SelectValue` 가 값 대신 이름을 보여 주고, 보이는 이름표가 없으면 `SelectTrigger` 에 `aria-label` 을 달아 주세요. `SelectItem` 은 고른 표시를 라디오나 체크박스로 바꾸는 `variant` 도 받아요.
