## 설치

```npm
npx shadcn@latest add @kcn-montage/empty
```

## 사용법

부품은 shadcn 의 Empty 와 같고 `size` · `padding` prop 이 더 있어요. `EmptyContent` 에는 outline 버튼을 넣는데, 기본 크기에서는 `size="lg"` 버튼을, `size="sm"` 에서는 기본 크기 버튼을 써요.
