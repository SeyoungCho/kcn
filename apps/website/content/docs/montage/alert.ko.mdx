## 설치

```npm
npx shadcn@latest add @kcn-montage/alert
```

부품은 shadcn 의 Alert 와 같고, 상태별 배리언트와 `AlertAction` 자리가 더 있어요. 아이콘을 맨 앞에 두면 배리언트의 색이 입혀져요.
