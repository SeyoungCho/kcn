## Installation

```npm
npx shadcn@latest add @kcn-montage/dropdown-menu
```

## Usage

The API matches shadcn's DropdownMenu, without submenus. Put `DropdownMenuLabel` inside a group — it stays at the top while the list scrolls. Checked items turn bold and blue with a check at the end, or show a checkbox or radio with `variant`. `DropdownMenuShortcut` holds a trailing value or icon, and `DropdownMenuFooter` pins actions to the bottom.
