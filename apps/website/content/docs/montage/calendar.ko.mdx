## 설치

```npm
npx shadcn@latest add @kcn-montage/calendar
```

## 사용법

API 는 shadcn 의 Calendar 와 같고 [React DayPicker](https://daypicker.dev) 위에 만들었어요. 늘 6주를 그리고, range 에서는 다른 달의 날을 감춰요.
