## 설치

```npm
npx shadcn@latest add @kcn-montage/combobox
```

## 사용법

API 는 shadcn 의 Combobox 와 같아요. `Combobox` 에 `items` 를 주고, `ComboboxList` 의 함수 자식으로 항목을 하나씩 그려요. `{ value, label }` 모양의 항목은 `label` 로 보여 주고 걸러요. 보이는 이름표가 없으면 `ComboboxInput` 에 `aria-label` 을 달아 주세요.
