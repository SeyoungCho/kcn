## Installation

```npm
npx shadcn@latest add @kcn-montage/popover
```

## Usage

The API matches shadcn's Popover. With a `PopoverHeader` inside, the popover becomes a compact message that can take `PopoverFooter` text buttons and a `showCloseButton` close button; without one it's a plain panel for any content.
