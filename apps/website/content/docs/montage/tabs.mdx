## Installation

```npm
npx shadcn@latest add @kcn-montage/tabs
```

## Usage

The API matches shadcn's Tabs. `TabsList` takes `variant` (`default` is a segmented control, plus `line`, `chip` and `chip-primary`), `size` and `fitted`, and draws the moving indicator for you. Arrow keys select a tab as soon as it gets focus.

```tsx
<Tabs defaultValue="details">
  <TabsList variant="line">
    <TabsTrigger value="details">Details</TabsTrigger>
    <TabsTrigger value="care">Care</TabsTrigger>
  </TabsList>
  <TabsContent value="details">…</TabsContent>
  <TabsContent value="care">…</TabsContent>
</Tabs>
```

<Preview registry="montage" demo="tabs/tabs-scrollable" height={200} />

### Fitted

`fitted` splits the list width evenly between tabs.

<Preview registry="montage" demo="tabs/tabs-fitted" height={160} />

### With Icon

Icon-only tabs need an `aria-label`; `fitted={false}` shrinks the list to fit its tabs.
