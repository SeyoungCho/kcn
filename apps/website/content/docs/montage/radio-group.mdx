## Installation

```npm
npx shadcn@latest add @kcn-montage/radio-group
```

## Usage

The API matches shadcn's RadioGroup; `RadioGroupItem` also takes `size` and `tight`. Wrap each item in a `<label>` with its text, and name the group with `aria-labelledby`.

```tsx
<RadioGroup defaultValue="daily" aria-labelledby="reminder-label">
  <label className="flex items-center gap-2">
    <RadioGroupItem value="daily" />
    Every day
  </label>
  <label className="flex items-center gap-2">
    <RadioGroupItem value="off" />
    Off
  </label>
</RadioGroup>
```
