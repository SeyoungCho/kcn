## Installation

```npm
npx shadcn@latest add @kcn-montage/drawer
```

## Usage

The API matches shadcn's Drawer, but it only opens from the bottom and can be swiped down to close. Blocks between `DrawerHeader` and `DrawerFooter` are padded and spaced for you, and footer buttons share the row, so give them `size="lg"`.
