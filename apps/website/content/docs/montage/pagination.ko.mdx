## 설치

```npm
npx shadcn@latest add @kcn-montage/pagination
```

## 사용법

API 는 shadcn 의 Pagination 과 같아요. 이전 · 다음은 아이콘만 있는 화살표이고, 첫 쪽 · 마지막 쪽에서는 `aria-disabled` 를 달아 주세요. `PaginationCounter` 와 `PaginationDots` 는 쪽 번호 없이 위치를 보여 주는 부품이에요.

```tsx
<Pagination>
  <PaginationContent>
    <PaginationItem>
      <PaginationPrevious href="#" />
    </PaginationItem>
    <PaginationItem>
      <PaginationLink href="#" isActive>
        1
      </PaginationLink>
    </PaginationItem>
    <PaginationItem>
      <PaginationEllipsis />
    </PaginationItem>
    <PaginationItem>
      <PaginationNext href="#" />
    </PaginationItem>
  </PaginationContent>
</Pagination>
```
