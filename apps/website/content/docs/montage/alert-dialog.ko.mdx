## 설치

```npm
npx shadcn@latest add @kcn-montage/alert-dialog
```

## 사용법

API 는 shadcn 의 AlertDialog 와 같지만 버튼이 글자 버튼이에요. `AlertDialogAction` 과 `AlertDialogCancel` 의 기본 `variant` 는 `link` 이고, 취소 버튼은 회색이에요. `AlertDialogAction` 은 창을 닫지 않으니 동작이 끝나면 직접 닫아 주세요.
