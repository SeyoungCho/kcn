## 설치

```npm
npx shadcn@latest add @kcn-montage/input-group
```

## 사용법

API 는 shadcn 의 InputGroup 과 같고, `variant` · `size` prop 이 더 있어요. `InputGroup` 이 입력 칸의 모양을 지고, 안에는 `InputGroupInput` 이나 `InputGroupTextarea` 를, `InputGroupAddon` 에는 아이콘 · 글 · 버튼을 넣어요. 아이콘만 있는 버튼에는 `aria-label` 을 꼭 달아 주세요.

## 예제

### 검색

`variant="secondary"` 는 회색으로 채운 검색 칸이고, 검색 칸(`type="search"`)에는 포커스 링이 없어요.
