## Installation

```npm
npx shadcn@latest add @kcn-montage/empty
```

## Usage

The parts match shadcn's Empty, with extra `size` and `padding` props. Put outline buttons in `EmptyContent`: `size="lg"` buttons for the default size, default-size buttons for `size="sm"`.
