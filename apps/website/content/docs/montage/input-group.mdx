## Installation

```npm
npx shadcn@latest add @kcn-montage/input-group
```

## Usage

The API matches shadcn's InputGroup, plus `variant` and `size` props. `InputGroup` takes the input's look; put an `InputGroupInput` or `InputGroupTextarea` inside and icons, text or buttons in an `InputGroupAddon`. Icon-only buttons need an `aria-label`.
