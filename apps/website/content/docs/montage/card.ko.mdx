## 설치

```npm
npx shadcn@latest add @kcn-montage/card
```

## 사용법

부품은 shadcn 의 Card 를 따르고, 썸네일을 담는 `CardMedia` 가 더 있어요. 카드에는 바탕 면이 없고, `render={<a />}` 로 그리면 카드 전체가 링크가 돼요.

```tsx
<Card>
  <CardMedia>
    <img src="/thumbnail.jpg" alt="" />
  </CardMedia>
  <CardHeader>
    <CardTitle>제목</CardTitle>
    <CardDescription>설명</CardDescription>
  </CardHeader>
  <CardFooter>{/* 배지 */}</CardFooter>
</Card>
```
