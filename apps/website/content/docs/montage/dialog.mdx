## Installation

```npm
npx shadcn@latest add @kcn-montage/dialog
```

## Usage

The API matches shadcn's Dialog. Content between `DialogHeader` and `DialogFooter` is padded for you, and footer buttons share the row, so give them `size="lg"`. Pass a width class such as `w-120` for a wider dialog.
