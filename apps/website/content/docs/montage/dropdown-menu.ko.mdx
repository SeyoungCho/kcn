## 설치

```npm
npx shadcn@latest add @kcn-montage/dropdown-menu
```

## 사용법

API 는 shadcn 의 DropdownMenu 와 같고, 하위 메뉴는 없어요. `DropdownMenuLabel` 은 묶음 안에 넣으면 목록을 스크롤해도 위에 남아요. 체크한 항목은 글자가 굵고 파래지며 끝에 체크가 붙고, `variant` 로 체크박스나 라디오를 보여 줄 수도 있어요. 끝에 붙는 값 · 아이콘은 `DropdownMenuShortcut` 에, 아래에 고정할 버튼은 `DropdownMenuFooter` 에 넣어요.
