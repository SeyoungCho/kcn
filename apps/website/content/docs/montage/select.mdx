## Installation

```npm
npx shadcn@latest add @kcn-montage/select
```

## Usage

The API matches shadcn's Select. Pass `items` to `Select` so `SelectValue` shows the label instead of the raw value, and give `SelectTrigger` an `aria-label` when there is no visible label. `SelectItem` also takes a `variant` that shows the selection as a radio or checkbox.
