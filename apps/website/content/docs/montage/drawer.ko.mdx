## 설치

```npm
npx shadcn@latest add @kcn-montage/drawer
```

## 사용법

API 는 shadcn 의 Drawer 와 같지만 아래에서만 열리고, 끌어내려 닫을 수 있어요. `DrawerHeader` 와 `DrawerFooter` 사이의 블록에는 여백과 간격이 알아서 붙고, 버튼 줄의 버튼은 폭을 나눠 가지니 `size="lg"` 로 넣어 주세요.
