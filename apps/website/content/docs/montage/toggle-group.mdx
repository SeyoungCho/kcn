## Installation

```npm
npx shadcn@latest add @kcn-montage/toggle-group
```

## Usage

The API matches shadcn's ToggleGroup, except the items stand apart instead of joining into one bar. `variant` and `size` on the group apply to every item.

```tsx
<ToggleGroup defaultValue={["all"]}>
  <ToggleGroupItem value="all">All</ToggleGroupItem>
  <ToggleGroupItem value="foliage">Foliage</ToggleGroupItem>
</ToggleGroup>
```
