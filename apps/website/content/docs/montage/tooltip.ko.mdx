## 설치

```npm
npx shadcn@latest add @kcn-montage/tooltip
```

## 사용법

API 는 shadcn 의 Tooltip 과 같고, `TooltipContent` 의 `size` prop 과 `TooltipShortcut` 이 더 있어요. 열고 닫히기까지의 기다림은 `TooltipProvider` 가 정하니 앱 위쪽에 하나 두세요.
