## 설치

```npm
npx shadcn@latest add @kcn-montage/popover
```

## 사용법

API 는 shadcn 의 Popover 와 같아요. 안에 `PopoverHeader` 를 넣으면 짧은 메시지 모양이 되고, `PopoverFooter` 의 글자 버튼과 `showCloseButton` 닫기 버튼을 달 수 있어요. 넣지 않으면 아무 내용이나 담는 판이에요.
