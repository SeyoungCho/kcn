## Installation

```npm
npx shadcn@latest add @kcn-montage/item
```

## Usage

The API matches shadcn's Item. Render an `<a>` or `<button>` to make a row pressable; mark the chosen row with `aria-current` and an unavailable one with `aria-disabled`.

```tsx
<ItemGroup>
  <Item render={<button type="button" />}>
    <ItemMedia>
      <BellIcon />
    </ItemMedia>
    <ItemContent>
      <ItemTitle>Notifications</ItemTitle>
      <ItemDescription>Watering reminders and order updates</ItemDescription>
    </ItemContent>
    <ItemActions>
      <ChevronRightIcon />
    </ItemActions>
  </Item>
</ItemGroup>
```
