## 설치

```npm
npx shadcn@latest add @kcn-montage/tabs
```

## 사용법

API 는 shadcn 의 Tabs 와 같아요. `TabsList` 에 `variant`(`default` 는 세그먼트 컨트롤, 그 밖에 `line` · `chip` · `chip-primary`), `size`, `fitted` 를 주면 움직이는 표시는 알아서 그려져요. 화살표 키로 초점을 옮기면 바로 그 탭이 골라져요.

```tsx
<Tabs defaultValue="details">
  <TabsList variant="line">
    <TabsTrigger value="details">상품 정보</TabsTrigger>
    <TabsTrigger value="care">키우는 법</TabsTrigger>
  </TabsList>
  <TabsContent value="details">…</TabsContent>
  <TabsContent value="care">…</TabsContent>
</Tabs>
```
