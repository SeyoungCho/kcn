## Installation

```npm
npx shadcn@latest add @kcn-montage/toast
```

## Usage

Mount `<Toaster />` once, then call `toast.add()` from anywhere:

```tsx
import { Toaster, toast } from "@/components/ui/toast";

<Toaster />;

toast.add({ title: "Saved", type: "success" });
```

Add `description`, `actionProps` or `data.closeButton` for a heading with an action and a close button. Use `priority: "high"` for errors so screen readers announce them right away.
