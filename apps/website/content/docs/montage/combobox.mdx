## Installation

```npm
npx shadcn@latest add @kcn-montage/combobox
```

## Usage

The API matches shadcn's Combobox. Pass `items` to `Combobox` and render each one from a function child of `ComboboxList`; `{ value, label }` items are shown and filtered by `label`. Give `ComboboxInput` an `aria-label` when there is no visible label.
