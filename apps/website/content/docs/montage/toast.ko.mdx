## 설치

```npm
npx shadcn@latest add @kcn-montage/toast
```

## 사용법

`<Toaster />` 를 한 번 두고, 어디서든 `toast.add()` 를 불러요.

```tsx
import { Toaster, toast } from "@/components/ui/toast";

<Toaster />;

toast.add({ title: "저장했어요", type: "success" });
```

`description` · `actionProps` · `data.closeButton` 을 주면 제목 아래 설명과 액션 · 닫기 버튼이 붙어요. 오류는 스크린 리더가 바로 읽도록 `priority: "high"` 로 띄워요.
