## Installation

```npm
npx shadcn@latest add @kcn-montage/checkbox
```

## Usage

The API matches shadcn's Checkbox, plus `variant` (`default`, `circle`, `check`), `size` and `tight`. Wrap it in a `<label>` with its text (or use `Field`) so the text toggles it too — otherwise give it an `aria-label`.

```tsx
<label className="flex items-center gap-2">
  <Checkbox defaultChecked />I agree to the Terms of Service
</label>
```
