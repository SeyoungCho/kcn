## 설치

```npm
npx shadcn@latest add @kcn-montage/skeleton
```

## 사용법

API 는 shadcn 의 Skeleton 과 같고, 모양을 고르는 `variant` prop 이 더 있어요. 기본으로 너비를 꽉 채우고, 크기 · 둥글기 · 색은 `className` 으로 줘요.

## 예제

### 배리언트

`text` 는 글자 한 줄, `rectangle` 은 이미지나 카드, `circle` 은 아바타 자리에 써요.
