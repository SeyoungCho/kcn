## Installation

```npm
npx shadcn@latest add @kcn-montage/alert-dialog
```

## Usage

The API matches shadcn's AlertDialog, but its actions are text buttons: `AlertDialogAction` and `AlertDialogCancel` default to `variant="link"`, and the cancel button is muted. `AlertDialogAction` doesn't close the dialog — close it yourself when the action is done.
