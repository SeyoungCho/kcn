## Installation

```npm
npx shadcn@latest add @kcn-montage/slider
```

## Usage

The API matches shadcn's Slider, plus `heading` and `label`. Point `aria-labelledby` at a label (or use `Field`) so screen readers can name each thumb.

## Examples

### Range

Pass an array to `defaultValue` for two thumbs; they swap places when dragged past each other.

<Preview registry="montage" demo="slider/slider-range" height={120} />

### Label

`label` puts text under each thumb; pass a function, e.g. ``label={(value) => `${value} h`}``, to build it from that thumb's value.

<Preview registry="montage" demo="slider/slider-label" height={140} />

### Heading

`heading` puts a title above the track; as a function it receives every thumb's value.

<Preview registry="montage" demo="slider/slider-heading" height={200} />
