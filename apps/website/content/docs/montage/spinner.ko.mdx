## 설치

```npm
npx shadcn@latest add @kcn-montage/spinner
```

## 사용법

API 는 shadcn 의 Spinner(`role="status"` 가 달린 `<svg>`)와 같고, `variant` prop 이 더 있어요. 크기는 `size-*` 클래스로 정해요.

### 배리언트
