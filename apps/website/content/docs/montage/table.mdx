## Installation

```npm
npx shadcn@latest add @kcn-montage/table
```

## Usage

The API matches shadcn's Table. The table sits in a rounded frame that scrolls on its own, and `interactive` on `TableRow` makes a row pressable.

```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead>Order</TableHead>
      <TableHead>Item</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow>
      <TableCell>LL-2481</TableCell>
      <TableCell>Monstera deliciosa</TableCell>
    </TableRow>
  </TableBody>
</Table>
```
