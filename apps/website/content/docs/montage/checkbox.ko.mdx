## 설치

```npm
npx shadcn@latest add @kcn-montage/checkbox
```

## 사용법

API 는 shadcn 의 Checkbox 와 같고, `variant`(`default` · `circle` · `check`) · `size` · `tight` 가 더 있어요. 글자와 함께 `<label>` 로 감싸거나 `Field` 를 써서 글자를 눌러도 바뀌게 하고, 보이는 글자가 없으면 `aria-label` 을 달아 주세요.

```tsx
<label className="flex items-center gap-2">
  <Checkbox defaultChecked />
  서비스 이용약관에 동의해요
</label>
```
