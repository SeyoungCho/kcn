## Installation

```npm
npx shadcn@latest add @kcn-montage/textarea
```

## Usage

The API matches shadcn's Textarea, plus a `size` prop, with the same states as `Input`. It starts two lines tall and grows with the content (CSS `field-sizing`); cap it with `max-h-*`. For buttons below the text, use `InputGroupTextarea`.
