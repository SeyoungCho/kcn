## 설치

```npm
npx shadcn@latest add @kcn-montage/input
```

## 사용법

API 는 shadcn 의 Input 과 같고, `size` prop 이 더 있어요. 라벨과 도움말은 `Field` 로, 칸 안의 아이콘 · 단위 · 버튼은 `InputGroup` 으로 붙여요. `aria-invalid` 가 붙으면 에러 상태가 되고, `<Field invalid>` 안에서는 저절로 붙어요.
