## Installation

```npm
npx shadcn@latest add @kcn-montage/accordion
```

## Usage

The API matches shadcn's Accordion, with `variant` and `size` on `Accordion`. Opening an item closes the others unless you pass `multiple`.

```tsx
<Accordion multiple>
  <AccordionItem value="watering">
    <AccordionTrigger>How often should I water?</AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```
