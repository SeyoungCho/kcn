## Installation

```npm
npx shadcn@latest add @kcn-montage/toggle
```

## Usage

The API matches shadcn's Toggle, plus an `icon` variant and an `xs` size. Put `data-icon="inline-start"` or `"inline-end"` on an icon next to text so the spacing fits.

```tsx
<Toggle>
  <PlusIcon data-icon="inline-start" />
  Add
</Toggle>
```
