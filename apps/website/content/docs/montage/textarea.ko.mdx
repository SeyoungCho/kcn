## 설치

```npm
npx shadcn@latest add @kcn-montage/textarea
```

## 사용법

API 는 shadcn 의 Textarea 와 같고 `size` prop 이 더 있으며, 상태는 `Input` 과 같아요. 처음에는 두 줄 높이이고 내용을 따라 늘어나요(CSS `field-sizing`). 최대 높이는 `max-h-*` 로 정해요. 글 아래에 버튼을 두려면 `InputGroupTextarea` 를 써요.
