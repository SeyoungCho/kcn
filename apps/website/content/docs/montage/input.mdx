## Installation

```npm
npx shadcn@latest add @kcn-montage/input
```

## Usage

The API matches shadcn's Input, plus a `size` prop. Add a label and help text with `Field`, and icons, units or buttons inside the input with `InputGroup`. `aria-invalid` shows the error state; `<Field invalid>` sets it for you.
