## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/spinner
```

## 사용법

API 는 shadcn 의 Spinner 와 같고(`role="status"` 를 가진 `<svg>`), `variant` 와 `size` 가 더 있어요. 금방 끝나는 로딩에 깜빡이지 않도록 잠깐 기다렸다가 나타나요. 선이 `currentColor` 라 `text-*` 클래스로도 색을 바꿀 수 있어요.
