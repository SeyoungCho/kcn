```npm
npx shadcn@latest add @kcn-t-flavored/rating
```

## 사용법

Base UI 에는 별점 부품이 없어서, 점수를 매기는 Rating 은 RadioGroup 위에 별마다 Radio 를 하나씩 놓았어요. 화살표 키로 별을 옮겨 다니고 스크린 리더가 고른 점수를 읽어요. `aria-label` 을 달고, `getItemLabel` 로 별마다 이름을 붙여 주세요.

### 읽기 전용
