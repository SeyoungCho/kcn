## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/alert-dialog
```

## Usage

The API matches shadcn's AlertDialog. Use one `<AlertDialogAction variant="link">` to acknowledge a message, or pair `AlertDialogCancel` with `AlertDialogAction` to ask for a choice. `AlertDialogAction` doesn't close the dialog — close it yourself when the action is done.
