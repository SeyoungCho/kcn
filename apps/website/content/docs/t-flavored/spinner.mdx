## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/spinner
```

## Usage

The API matches shadcn's Spinner (an `<svg>` with `role="status"`), with extra `variant` and `size` props. It waits a moment before fading in, so quick loads don't flash. The stroke is `currentColor`, so `text-*` classes recolor it.
