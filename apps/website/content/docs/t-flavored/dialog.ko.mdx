## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/dialog
```

## 사용법

API 는 shadcn 의 Dialog 와 같아요. 다만 닫기 버튼은 기본으로 감춰져 있어서, 보이려면 `showCloseButton` 을 넘겨요.

## 예제

### 머리와 버튼 줄

버튼 줄의 버튼은 한 줄을 나눠 갖고, 나란히 들어가지 않으면 한 줄씩 쌓여요.
