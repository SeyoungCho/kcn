## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/input-group
```

## Usage

The API matches shadcn's InputGroup. `InputGroup` takes `Input`'s look and variants; put an `InputGroupInput` inside and text, icons or buttons in an `InputGroupAddon` on either side. `variant="search"` is a grey search box; show its clear button only while there is a value.
