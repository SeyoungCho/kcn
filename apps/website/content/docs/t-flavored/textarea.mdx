## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/textarea
```

## Usage

The API matches shadcn's Textarea, with the same variants and states as `Input`, and it works inside `Field` the same way. The height follows the content (CSS `field-sizing`); set a minimum with `min-h-*` or fix it with `h-*`.
