## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/badge
```

## Usage

The API matches shadcn's Badge, with an extra `size` prop. `variant` sets color and weight together: each color comes as a fill and a lighter `-weak` tint (`default` / `weak` are blue, `dark` / `secondary` grey).
