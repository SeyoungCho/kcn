## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/toast
```

## Usage

Mount `<Toaster />` once, then call `toast.add()` from anywhere:

```tsx
import { Toaster, toast } from "@/components/ui/toast";

<Toaster />;

toast.add({ title: "Saved", type: "success", data: { position: "top" } });
```

One toast shows at a time. Set `position` on the `Toaster`, or per toast with `data.position`.
