t-flavored is a shadcn/ui registry inspired by the Toss Design System (TDS). Its components are built on Base UI and Tailwind CSS 4 and keep shadcn's API, so they fit into any shadcn project.

## Installation

Add the style first. It sets up the color, typography and radius tokens, including dark mode.

```npm
npx shadcn@latest add @kcn-t-flavored/t-flavored-style
```

Then add the components you need.

```npm
npx shadcn@latest add @kcn-t-flavored/button
```
