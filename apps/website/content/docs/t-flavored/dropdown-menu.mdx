## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/dropdown-menu
```

## Usage

The API matches shadcn's DropdownMenu, without the `DropdownMenuSub*` parts. Put `DropdownMenuLabel` inside a `DropdownMenuGroup`.
