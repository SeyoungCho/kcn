## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/accordion
```

## Usage

The API matches shadcn's Accordion. Opening a row closes the others unless you pass `multiple`.

For a prefix such as `Q`, put it before the title inside `AccordionTrigger`:

```tsx
<Accordion multiple>
  <AccordionItem value="watering">
    <AccordionTrigger>
      <span className="text-primary">Q</span>
      How often should I water?
    </AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```
