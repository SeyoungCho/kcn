## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/textarea
```

## 사용법

API 는 shadcn 의 Textarea 와 같고, `Input` 과 같은 배리언트 · 상태를 가지며 `Field` 안에서도 똑같이 써요. 높이는 내용을 따라가요(CSS `field-sizing`). 최소 높이는 `min-h-*`, 고정 높이는 `h-*` 로 줘요.
