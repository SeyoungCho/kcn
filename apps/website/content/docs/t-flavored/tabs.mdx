## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/tabs
```

## Usage

The API matches shadcn's Tabs. On `TabsList`, `variant="default"` is a segmented control and `variant="line"` is underlined tabs; the sliding indicator is drawn for you.

```tsx
<Tabs defaultValue="day">
  <TabsList>
    <TabsTrigger value="day">Day</TabsTrigger>
    <TabsTrigger value="week">Week</TabsTrigger>
  </TabsList>
  <TabsContent value="day">…</TabsContent>
  <TabsContent value="week">…</TabsContent>
</Tabs>
```
