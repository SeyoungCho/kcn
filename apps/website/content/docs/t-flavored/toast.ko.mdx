## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/toast
```

## 사용법

`<Toaster />` 를 한 번 두고, 어디서든 `toast.add()` 를 불러요.

```tsx
import { Toaster, toast } from "@/components/ui/toast";

<Toaster />;

toast.add({ title: "저장했어요", type: "success", data: { position: "top" } });
```

한 번에 하나만 보여요. `position` 은 `Toaster` 에 정하고, 토스트마다 `data.position` 으로 바꿀 수 있어요.
