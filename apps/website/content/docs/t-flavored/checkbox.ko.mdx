## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/checkbox
```

## 사용법

API 는 shadcn 의 Checkbox 와 같고, `variant` 가 더 있어요. `circle`(기본값)은 테 안에 체크를, `line` 은 체크만 그려요. 글자를 눌러도 선택되도록 `<label>` 로 감싸거나 `Field` 를 쓰고, 글자가 없으면 `aria-label` 을 꼭 달아 주세요.

```tsx
<label className="flex items-center gap-3">
  <Checkbox defaultChecked />
  서비스 이용약관에 동의해요
</label>
```
