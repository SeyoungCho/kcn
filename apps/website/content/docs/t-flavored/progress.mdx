## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/progress
```

## Usage

The API matches shadcn's Progress, built on Base UI's Progress, with an extra `size` prop for the bar's thickness. Name the bar with `aria-label` or `ProgressLabel`.
