## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/skeleton
```

## 사용법

API 는 shadcn 의 Skeleton 과 같아요. 막대 하나이고 크기와 둥글기는 `className` 으로 줘요. 줄마다 `--skeleton-delay` 를 조금씩 늘려 주면 위에서 아래로 차례로 깜빡여요(조상에 줘도 안의 막대가 따라요).
