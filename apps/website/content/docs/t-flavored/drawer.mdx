## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/drawer
```

## Usage

The API matches shadcn's Drawer, but it only opens from the bottom. Put `xl` buttons in `DrawerFooter`; anything between the header and the footer becomes the body, which scrolls when the sheet gets too tall.
