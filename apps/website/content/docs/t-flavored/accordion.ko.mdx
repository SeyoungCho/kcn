## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/accordion
```

## 사용법

API 는 shadcn 의 Accordion 과 같아요. `multiple` 을 주지 않으면 한 줄을 펼칠 때 다른 줄이 접혀요.

`Q` 같은 프리픽스는 `AccordionTrigger` 안에서 제목 앞에 두면 돼요.

```tsx
<Accordion multiple>
  <AccordionItem value="watering">
    <AccordionTrigger>
      <span className="text-primary">Q</span>
      물은 얼마나 자주 줘야 하나요?
    </AccordionTrigger>
    <AccordionContent>…</AccordionContent>
  </AccordionItem>
</Accordion>
```
