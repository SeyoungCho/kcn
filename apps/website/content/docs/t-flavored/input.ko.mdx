## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/input
```

## 사용법

API 는 shadcn 의 Input 과 같아요. 라벨과 도움말은 `Field` 로, 칸 안의 접두사 · 접미사 · 버튼은 `InputGroup` 으로 붙여요. `aria-invalid` 가 붙으면 에러 상태가 되고, `<Field invalid>` 안에서는 저절로 붙어요.

## 예제

### 배리언트

`default` 는 상자, `line` · `big` 은 밑줄, `hero` 는 테두리 없는 모양이에요.
