## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/dropdown-menu
```

## 사용법

API 는 shadcn 의 DropdownMenu 와 같고, `DropdownMenuSub*` 는 없어요. `DropdownMenuLabel` 은 `DropdownMenuGroup` 안에 넣어요.
