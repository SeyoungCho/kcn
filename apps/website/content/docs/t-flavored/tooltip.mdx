## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/tooltip
```

## Usage

The API matches shadcn's Tooltip, with an extra `size` prop on `TooltipContent` and `side` limited to `top` or `bottom` (`bottom` by default). Only one uncontrolled tooltip stays open at a time — pass `open` to keep several open.
