## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/skeleton
```

## Usage

The API matches shadcn's Skeleton: one bar, sized and rounded with `className`. To make rows pulse one after another from top to bottom, give each row a slightly larger `--skeleton-delay` — bars inherit it from any ancestor.
