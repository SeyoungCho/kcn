## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/alert-dialog
```

## 사용법

API 는 shadcn 의 AlertDialog 와 같아요. 알리기만 할 때는 `<AlertDialogAction variant="link">` 하나를, 선택을 받을 때는 `AlertDialogCancel` 과 `AlertDialogAction` 을 함께 써요. `AlertDialogAction` 은 다이얼로그를 닫지 않으니 동작이 끝나면 직접 닫아 주세요.
