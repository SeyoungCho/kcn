## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/progress
```

## 사용법

API 는 shadcn 의 Progress 와 같고 Base UI 의 Progress 위에 만들었어요. 막대 두께를 고르는 `size` 가 더 있어요. `aria-label` 이나 `ProgressLabel` 로 막대에 이름을 붙여 주세요.
