## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/number-field
```

## 사용법

Base UI 의 NumberField 위에 만들고, shadcn 처럼 부품으로 나눴어요.

```tsx
<NumberField size="lg" defaultValue={0}>
  <NumberFieldGroup>
    <NumberFieldDecrement aria-label="상품 수량 줄이기" />
    <NumberFieldInput aria-label="수량" />
    <NumberFieldIncrement aria-label="상품 수량 늘리기" />
  </NumberFieldGroup>
</NumberField>
```

부품마다 `aria-label` 을 꼭 달아 주세요. 안 달면 버튼 이름이 Base UI 의 영어 "Decrease" / "Increase" 가 돼요.
