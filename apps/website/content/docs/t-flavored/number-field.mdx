## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/number-field
```

## Usage

Built on Base UI's NumberField and split into shadcn-style parts:

```tsx
<NumberField size="lg" defaultValue={0}>
  <NumberFieldGroup>
    <NumberFieldDecrement aria-label="Decrease quantity" />
    <NumberFieldInput aria-label="Quantity" />
    <NumberFieldIncrement aria-label="Increase quantity" />
  </NumberFieldGroup>
</NumberField>
```

Give every part an `aria-label` — otherwise the buttons fall back to Base UI's English "Decrease" / "Increase".
