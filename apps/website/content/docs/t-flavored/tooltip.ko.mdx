## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/tooltip
```

## 사용법

API 는 shadcn 의 Tooltip 과 같고, `TooltipContent` 에 `size` 가 더 있어요. `side` 는 `top` · `bottom` 만 되고 기본은 `bottom` 이에요. 제어하지 않는 툴팁은 한 번에 하나만 열리니, 여러 개를 열어 두려면 `open` 을 넘겨요.
