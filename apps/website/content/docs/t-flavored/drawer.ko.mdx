## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/drawer
```

## 사용법

API 는 shadcn 의 Drawer 와 같지만 아래에서만 올라와요. `DrawerFooter` 에는 `xl` 버튼을 넣고, 머리와 버튼 줄 사이에 넣은 것은 본문이 돼요. 시트가 너무 길어지면 본문이 스크롤돼요.
