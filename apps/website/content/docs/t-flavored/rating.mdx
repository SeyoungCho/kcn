## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/rating
```

## Usage

Base UI has no rating primitive, so the interactive rating is a RadioGroup with one Radio per star: arrow keys move between stars and screen readers announce the choice. Give it an `aria-label`, and `getItemLabel` to name each star.

### Read-only

`readOnly` only shows a score, laid out by `variant`: `default` (stars + score), `compact` (one star + score) or `icon-only` (stars only).
