## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/badge
```

## 사용법

API 는 shadcn 의 Badge 와 같고 `size` 가 더 있어요. `variant` 하나로 색과 세기를 함께 골라요. 색마다 채운 모양과 연한 `-weak` 가 짝을 이뤄요(`default` · `weak` 는 파랑, `dark` · `secondary` 는 회색).
