## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/input
```

## Usage

The API matches shadcn's Input. Add a label and help text with `Field`, and prefixes, suffixes or buttons inside the field with `InputGroup`. `aria-invalid` shows the error state; `<Field invalid>` sets it for you.

## Examples

`default` is a box, `line` and `big` are underlined, and `hero` has no border.
