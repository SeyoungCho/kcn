## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/input-group
```

## 사용법

API 는 shadcn 의 InputGroup 과 같아요. `InputGroup` 이 `Input` 의 모양 · 배리언트를 지고, 안에는 `InputGroupInput` 을, 양옆의 `InputGroupAddon` 에는 글 · 아이콘 · 버튼을 넣어요. `variant="search"` 는 회색 검색창이고, 지우기 버튼은 값이 있을 때만 보여 주세요.
