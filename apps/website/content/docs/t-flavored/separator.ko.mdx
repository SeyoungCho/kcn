## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/separator
```

## 사용법

API 는 shadcn 의 Separator 와 같고 Base UI 의 Separator 위에 만들었어요. `variant` 가 더 있어요.

## 예제

### 왼쪽에 여백 주기

`inset` 은 선 앞을 띄워 항목의 글과 줄을 맞춰요.

<Preview registry="t-flavored" demo="separator/separator-inset" height={240} />

### 구간 나누기

`section` 은 굵은 회색 띠로 구간을 나누고, 두께는 `h-*` 로 바꿔요.
