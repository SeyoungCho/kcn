## Installation

```npm
npx shadcn@latest add @kcn-t-flavored/checkbox
```

## Usage

The API matches shadcn's Checkbox, plus a `variant`: `circle` (the default) draws the check inside a ring, `line` draws the check alone. Wrap it in a `<label>` (or use `Field`) so the text toggles it too — otherwise give it an `aria-label`.

```tsx
<label className="flex items-center gap-3">
  <Checkbox defaultChecked />I agree to the Terms of Service
</label>
```
