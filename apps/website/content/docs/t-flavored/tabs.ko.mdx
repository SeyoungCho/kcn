## 설치

```npm
npx shadcn@latest add @kcn-t-flavored/tabs
```

## 사용법

API 는 shadcn 의 Tabs 와 같아요. `TabsList` 의 `variant="default"` 는 세그먼트 컨트롤, `variant="line"` 은 밑줄 탭이고, 움직이는 표시는 알아서 그려져요.

```tsx
<Tabs defaultValue="day">
  <TabsList>
    <TabsTrigger value="day">일간</TabsTrigger>
    <TabsTrigger value="week">주간</TabsTrigger>
  </TabsList>
  <TabsContent value="day">…</TabsContent>
  <TabsContent value="week">…</TabsContent>
</Tabs>
```
