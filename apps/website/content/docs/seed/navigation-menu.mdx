## Installation

```npm
npx shadcn@latest add @kcn-seed/navigation-menu
```

## Usage

`NavigationMenuProvider` tracks which menu is open, so only one is open at a time and moving to a neighbor swaps instantly without waiting for `openDelay`. Each `NavigationMenuRoot` pairs one `NavigationMenuTrigger` with its `NavigationMenuContent` and renders no element of its own. Items are plain buttons (`NavigationMenuItem`) and close the menu when pressed. Pass `render` to `NavigationMenuTrigger` to use your own button.

## Examples

### Groups

Wrap items in `NavigationMenuGroup` with a `NavigationMenuGroupLabel`. Consecutive groups are separated by a divider.
