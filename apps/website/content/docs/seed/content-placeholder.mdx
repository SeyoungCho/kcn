## Installation

```npm
npx shadcn@latest add @kcn-seed/content-placeholder
```

## Usage

`ContentPlaceholder` fills its parent, so size it with a wrapper such as an image frame or a card's thumbnail slot. The illustration is half the panel's height, up to 160px. It is decorative; give the panel `role="img"` and an `aria-label` when it needs a name.
