`fallback` 은 `src` 가 없을 때, 사진을 읽는 중일 때, 읽지 못했을 때 보입니다. `IdentityPlaceholder`(`identity="person"` · `"business"`)에 화면 낭독기용 `label` 을 줘서 넣으세요.
