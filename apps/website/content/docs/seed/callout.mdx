## Installation

```npm
npx shadcn@latest add @kcn-seed/callout
```

## Usage

The file exports three components: `Callout` (static), `ActionableCallout` (the whole box is a button and ends with a chevron), and `DismissibleCallout` (ends with a close button). `title`, `description`, and the optional link run together on one line.

`DismissibleCallout`'s close button is labeled `닫기` by default; pass `closeLabel` for other languages.
