## Installation

```npm
npx shadcn@latest add @kcn-seed/radio-group
```

## Usage

`RadioGroup` holds the value and renders the label, description, and error message. Put one `RadioGroupItem` per option inside it; `tone` and `size` are set per item.

## Examples

### Horizontal

`className` goes on the element that holds the options, so `flex-row` lays them out in a row.
