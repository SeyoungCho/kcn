## 설치

```npm
npx shadcn@latest add @kcn-seed/floating-toolbar
```

## 사용법

`FloatingToolbar` 는 `document.body` 에 그려져 표나 스크롤 상자에 잘리지 않고, 화면의 `main` 요소 가운데에 뜹니다(없으면 화면 전체 가운데). 안에 `FloatingToolbarLabel` · `FloatingToolbarSeparator` · `FloatingToolbarButton` 을 넣습니다. `onDismiss` 를 주면 옆에 닫기 버튼이 생기고 Esc 로도 닫힙니다. 할 일이 넘치면 휠이나 마우스 끌기로 옆으로 밉니다.

## 예제

### 고르기와 함께

무언가를 골랐을 때 열고, `onDismiss` 에서 고르기를 풉니다.
