## Installation

```npm
npx shadcn@latest add @kcn-seed/tag-group
```

## Usage

`TagGroupRoot` places a separator between its `TagGroupItem` children. The `size`, `weight`, and `tone` set on the root apply to every item; set them on an item to override just that one.

### Truncate

With `truncate`, the group stays on one line and cuts overflowing items with an ellipsis. Without it, items wrap.
