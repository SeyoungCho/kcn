seed 는 당근의 디자인 시스템 [SEED Design](https://seed-design.io/)에서 영감을 받아 만든 shadcn/ui 레지스트리예요. 컴포넌트는 Base UI 와 Tailwind CSS 4 로 만들었고 shadcn 의 API 를 그대로 따라서, 어떤 shadcn 프로젝트에도 바로 넣을 수 있어요.

## 설치

먼저 스타일을 추가하세요. 다크 모드를 포함한 색 · 글자 · 간격 · 모서리 · 그림자 · 움직임 토큰이 설정돼요.

```npm
npx shadcn@latest add @kcn-seed/seed-style
```

그다음 필요한 컴포넌트를 추가하세요.

```npm
npx shadcn@latest add @kcn-seed/action-button
```

아이콘은 `@karrotmarket/react-monochrome-icon` 을 써요. 아이콘이 필요한 컴포넌트를 추가하면 CLI 가 함께 설치해요.
