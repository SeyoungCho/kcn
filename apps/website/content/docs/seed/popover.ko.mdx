## 설치

```npm
npx shadcn@latest add @kcn-seed/popover
```

## 사용법

자리 잡는 값(`placement` · `gutter` …)은 `PopoverRoot` 에 줍니다. `PopoverContent` 는 `title` · `description` · 닫기 버튼을 갖춘 창을 그립니다. 내용은 `PopoverBody` 에, 버튼은 `PopoverFooter` 에 넣으세요. `PopoverAction` 은 누르면 창이 닫히는 `ActionButton` 입니다.
