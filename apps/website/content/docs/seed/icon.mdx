## Installation

```npm
npx shadcn@latest add @kcn-seed/icon
```

## Usage

`Icon` renders the element you pass as `svg` (such as `<IconHeartLine />`) without adding a wrapper. Its size and color come from the parent component through `--icon-size` and `--icon-color`; `size` and `color` override them. `PrefixIcon` and `SuffixIcon` (from `affix-icon`) are for icons before or after text inside components like `ActionButton` — the parent sets their size, color, and spacing.
