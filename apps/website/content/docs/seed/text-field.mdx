## Installation

```npm
npx shadcn@latest add @kcn-seed/text-field
```

## Usage

`TextField` renders the label, description, error message, and counter around the control you pass as children — `TextFieldInput` or `TextFieldTextarea`. Compose `TextFieldRoot` with the `Field` parts directly when you need a custom layout.

### Textarea with Character Count

`maxGraphemeCount` counts user-perceived characters (emoji and combined Hangul count as one). It does not cut the value — read `slicedValue` from `onValueChange` if you want to enforce the limit.
