## 설치

```npm
npx shadcn@latest add @kcn-seed/callout
```

## 사용법

`Callout`(그냥 알림 상자), `ActionableCallout`(통째로 누르는 버튼, 끝에 `>` 가 붙음), `DismissibleCallout`(끝에 닫기 버튼이 붙음) 세 가지를 내보냅니다. `title` · `description` · 링크는 한 줄로 이어집니다.
