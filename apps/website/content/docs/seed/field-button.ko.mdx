## 설치

```npm
npx shadcn@latest add @kcn-seed/field-button
```

## 사용법

`FieldButton` 은 칸에 이름표 · 도움말 · 오류 메시지를 둘러요. 이름표 없이 쓰거나 직접 짠 `Field` 안에 놓을 때는 칸만 있는 `FieldButtonControl` 을 써요. children 으로 고른 값(`FieldButtonValue`)이나 안내 글(`FieldButtonPlaceholder`)을 넣어요. 둘 다 화면에만 보이므로, 칸 이름과 값을 알려 주는 `aria-label` 을 고르는 창을 여는 `onClick` 과 함께 `buttonProps` 로 줘요.

이름표를 누르면 버튼에 초점만 가고 아무것도 열리지 않아요. `values` 는 숨은 input 으로 폼에 실려요.
