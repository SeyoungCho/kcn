## Installation

```npm
npx shadcn@latest add @kcn-seed/field-button
```

## Usage

`FieldButton` renders the label, description, and error message around the field; `FieldButtonControl` is the field alone, for use without a label or inside your own `Field`. Put `FieldButtonValue` (the chosen value) or `FieldButtonPlaceholder` inside as children. Both are visual only, so pass an `aria-label` that names the field and its value through `buttonProps`, together with the `onClick` that opens your picker.

Pressing the label focuses the button without opening anything. `values` are submitted with a form as hidden inputs.
