## Installation

```npm
npx shadcn@latest add @kcn-seed/date-picker
```

## Usage

Dates are plain `{ year, month, day }` objects (`month` runs from 1 to 12) with no time or time zone. Press the month title to jump to another year and month with a wheel. `DatePicker` shows one month; `TwoMonthDatePicker` shows two side by side.

## Examples

### Range

With `selectionMode="range"`, the value is `{ start, end? }` — `end` is missing while only the start is picked.

### Constraints

Every function in `constraints` must return `true` for a date to be pickable. `dateOnOrAfter` and `dateOnOrBefore` cover min and max dates; any `(date) => boolean` works for the rest. Unavailable dates are struck through.
