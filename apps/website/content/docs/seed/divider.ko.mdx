## 설치

```npm
npx shadcn@latest add @kcn-seed/divider
```

## 사용법

기본 `<hr>` 은 구분선으로 읽힙니다. 꾸밈일 뿐이면 `as="div"` 로 그리고, `hr` 이 아닌 요소를 읽히게 하려면 `role="separator"` 를 주세요.

## 예제

### 세로
