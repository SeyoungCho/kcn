## Installation

```npm
npx shadcn@latest add @kcn-seed/layout
```

## Usage

`Layout` fills the screen height (`h-screen`) and scrolls. `LayoutContent` centers the page body and limits its width according to the `density` of the surrounding `Layout`. The limits apply from 768px wide screens, so narrow previews show the content at full width. Both accept `render` to change the rendered element (for example `render={<main />}`).
