## 설치

```npm
npx shadcn@latest add @kcn-seed/layout
```

## 사용법

`Layout` 은 화면 높이(`h-screen`)를 채우고 안에서 스크롤합니다. `LayoutContent` 는 본문을 가운데에 놓고, 바깥 `Layout` 의 `density` 에 따라 폭을 묶습니다. 폭 제한은 768px 이상 화면부터 걸리므로 좁은 미리보기에서는 본문이 꽉 찹니다. 둘 다 `render` 로 그려질 요소를 바꿀 수 있습니다(예: `render={<main />}`).
