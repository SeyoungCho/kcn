## Installation

```npm
npx shadcn@latest add @kcn-seed/alert-dialog
```

## Usage

Compose `AlertDialogContent` from `AlertDialogHeader` (with `AlertDialogTitle` and `AlertDialogDescription`) and `AlertDialogFooter`. `AlertDialogAction` is an `ActionButton` that closes the dialog when pressed. Pressing outside never closes an alert dialog; focus starts on the dialog itself, so pressing Enter right after it opens doesn't trigger an action.
