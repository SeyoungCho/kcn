## Installation

```npm
npx shadcn@latest add @kcn-seed/image-frame
```

## Usage

`ImageFrame` sizes itself by its width and `ratio`; the image is cropped to cover the frame. Place overlays as children inside `ImageFrameFloater`, then use `ImageFrameIndicator` for counts, `ImageFrameIcon` for white icons, and `ImageFrameReactionButton` for a like toggle.
