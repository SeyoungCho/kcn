## Installation

```npm
npx shadcn@latest add @kcn-seed/chip
```

## Usage

There are three kinds of chip that share one look: `ToggleChip` turns on and off like a checkbox, `RadioChipItem` inside `RadioChipRoot` picks one of several, and `ButtonChip` is a plain button. Put `ChipLabel`, `ChipPrefixIcon`, and `ChipSuffixIcon` inside — they inherit the chip's `variant` and `size`.
