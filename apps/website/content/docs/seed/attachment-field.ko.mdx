## 설치

```npm
npx shadcn@latest add @kcn-seed/attachment-field
```

## 사용법

`AttachmentField` 는 이름표 · 도움말 · 오류 메시지를 더하고 항목을 쥡니다. 안에 `AttachmentInput`(80×80 고르는 버튼 옆으로 항목을 늘어놓는 칸) 또는 `AttachmentDropzone`(끌어 놓는 칸 아래로 항목을 늘어놓는 칸)을 놓습니다.

올리기는 부품이 하지 않습니다. 새로 받은 파일은 `onFileAccept` 로 `updateFileEntryStatus(id, details)` 도우미와 함께 옵니다 — 여기서 올리기를 시작하고 항목의 상태를 `pending` · `uploading`(0 ~ 100 의 `progress` 는 골라서) · `success` · `error` 로 넘기세요.
