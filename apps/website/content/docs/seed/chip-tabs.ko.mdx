## 설치

```npm
npx shadcn@latest add @kcn-seed/chip-tabs
```

## 사용법

`ChipTabsRoot` > `ChipTabsList` > `ChipTabsTrigger` 로 짜고, 칩마다 같은 `value` 의 `ChipTabsContent` 를 둡니다. `variant` · `size` 는 묶음에 주면 모든 칩에 적용됩니다. 화살표 키로 옮기면 바로 그 칩이 골라집니다.
