## Installation

```npm
npx shadcn@latest add @kcn-seed/popover
```

## Usage

Positioning props (`placement`, `gutter`, …) go on `PopoverRoot`. `PopoverContent` draws the panel with an optional `title`, `description`, and close button; put content in `PopoverBody` and buttons in `PopoverFooter`. `PopoverAction` is an `ActionButton` that closes the popover when pressed.
