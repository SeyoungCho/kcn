## 설치

```npm
npx shadcn@latest add @kcn-seed/wheel-picker
```

## 사용법

열은 모두 `columns` 로 넘깁니다 — 열마다 `id` · `options` · 값(`value` · `onValueChange` 또는 `defaultValue`)이 따로 있습니다. 휠은 끌기 · 마우스 휠 · 화살표 키 · 글자 치기로 움직입니다. 고르기 전체와 열마다 `aria-label` 을 주세요.
