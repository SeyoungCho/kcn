## 설치

```npm
npx shadcn@latest add @kcn-seed/skeleton
```

## 사용법

`width` · `height` 는 치수 토큰(`"x12"`) · `"full"` · px 숫자 · CSS 값을 받습니다. 글 한 줄 대신 놓을 때는 `height` 에 그 글의 줄 높이 토큰(`"lineHeight.t4"` 처럼)을 주세요.
