## Installation

```npm
npx shadcn@latest add @kcn-seed/side-navigation
```

## Usage

`SideNavigationProvider` holds the collapsed state; read or change it from anywhere inside (for example a button in the top bar) with `useSideNavigationContext()`. The menu also collapses on its own when the screen narrows past 1280px and expands when it widens again. Inside `SideNavigationRoot`, place `SideNavigationHeader` (with `SideNavigationTrigger` for the collapse button), a scrolling `SideNavigationContent` of `SideNavigationGroup`s, and an optional `SideNavigationFooter`. Put the page next to it in `SideNavigationInset`.

A group item with `items` is a parent: expanded, it opens its submenu inline; collapsed, the submenu opens beside it as a Navigation Menu.

## Examples

### Collapsed

Collapsed, only icons remain. Hovering an item shows its name in a tooltip, and parents open their submenu beside the menu.
