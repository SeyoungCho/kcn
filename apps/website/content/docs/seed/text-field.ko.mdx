## 설치

```npm
npx shadcn@latest add @kcn-seed/text-field
```

## 사용법

`TextField` 는 자식으로 받은 `TextFieldInput` 또는 `TextFieldTextarea` 둘레에 이름표 · 도움말 · 오류 메시지 · 글자 수를 그립니다. 배치를 직접 짜야 하면 `TextFieldRoot` 와 `Field` 부품을 조합하세요.
