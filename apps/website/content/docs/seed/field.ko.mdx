## 설치

```npm
npx shadcn@latest add @kcn-seed/field
```

## 사용법

`Field` 는 `TextField` 와 `FieldButton` 이 쓰는 틀이에요. 배치를 직접 짜야 할 때 바로 써요. 안에 `FieldHeader`(`FieldLabel` · `FieldRequiredIndicator` · `FieldIndicatorText`), `TextFieldRoot` 나 `FieldButtonControl` 같은 칸, `FieldFooter`(`FieldDescription` · `FieldErrorMessage` · `FieldCharacterCount`)를 놓아요.

`Field` 에 준 `required` · `disabled` · `invalid` · `readOnly` 는 모든 부품과 칸에 내려가요. 이름표는 칸과 이어지고, 실제로 그려진 도움말 · 오류 메시지만 `aria-describedby` 에 들어가요.

## 예제

### 상태

`TextField` 와 달리 `Field` 는 오류 메시지를 대신 숨기거나 보여 주지 않아요 — 오류일 때만 `FieldErrorMessage` 를 그려요.
