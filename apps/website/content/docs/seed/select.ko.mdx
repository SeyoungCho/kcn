### 상태

#### 비활성화(disabled)

루트의 `disabled` prop으로 셀렉트 전체를 비활성화합니다.

<Preview registry="seed" demo="select/select-disabled" height={400} />

#### 오류(invalid)

트리거에 `data-invalid` 속성을 부여하면 오류 상태로 표시됩니다.

<Preview registry="seed" demo="select/select-invalid" height={400} />

### 값 포맷팅(formatting the value)

기본적으로 `<SelectValue>`는 원본 `value`를 그대로 렌더링합니다.

#### `items` prop 사용

`<Select>`에 `items` prop을 전달하면 원본 값 대신 선택된 값에 해당하는 라벨을 렌더링합니다.

<Preview registry="seed" demo="select/select-format-items" height={400} />

#### `<SelectValue>` children에 함수 전달

`<SelectValue>`의 children으로 함수를 전달하면 값을 가공해서 렌더링할 수 있습니다.

<Preview registry="seed" demo="select/select-format-function" height={400} />
