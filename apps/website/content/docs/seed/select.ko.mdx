## 설치

```npm
npx shadcn@latest add @kcn-seed/select
```

## 사용법

`Select` 는 맨 셀렉트이고, `SelectRoot` 는 여기에 이름표 · 도움말 · 오류 메시지를 더합니다. 값은 하나를 고를 때도 `multiple` 일 때도 늘 배열입니다(`value={["apple"]}`). 버튼에는 고른 항목의 `label` 이 저절로 보입니다.
