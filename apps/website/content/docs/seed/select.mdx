## Installation

```npm
npx shadcn@latest add @kcn-seed/select
```

## Usage

`Select` is the bare select. `SelectRoot` wraps it with a label, description, and error message. Values are always arrays (`value={["apple"]}`), for single and `multiple` selection alike. The trigger shows the selected item's `label` automatically.
