## Installation

```npm
npx shadcn@latest add @kcn-seed/accordion
```

## Usage

Each `AccordionItem` holds an `AccordionTrigger` (the heading row, with `title` and optional `description`, `prefix`, `suffixIcon`) and an `AccordionContent`. Items inherit `variant` and `size` from `Accordion`. Expanded items are tracked as an array of item `value`s (`values` / `defaultValues`). `AccordionContent` has no padding of its own — add it to what you put inside.

## Examples

### Separated

`variant="separated"` puts each item in its own bordered box.
