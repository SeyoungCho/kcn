## Installation

```npm
npx shadcn@latest add @kcn-seed/wheel-picker
```

## Usage

Pass every column through `columns` — each one has its own `id`, `options`, and value (`value` / `onValueChange` or `defaultValue`). Wheels respond to dragging, the mouse wheel, arrow keys, and typing. Give the picker and each column an `aria-label`.
