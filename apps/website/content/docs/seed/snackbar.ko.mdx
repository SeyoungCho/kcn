## 사용법

앱을 `SnackbarProvider` 로 한 번 감싼 뒤, `useSnackbarAdapter()` 의 `create({ render: () => <Snackbar … /> })` 로 띄웁니다. 스낵바는 한 번에 하나만 보입니다. 기본(`strategy="immediate"`)은 새것이 떠 있는 것을 바로 바꾸고, `"queued"` 는 앞의 것이 끝나길 기다립니다. 마우스를 올리거나 키보드 초점이 가 있는 동안에는 시간이 멈춥니다.

```tsx
const snackbar = useSnackbarAdapter();

snackbar.create({
  render: () => (
    <Snackbar
      message="장바구니에서 몬스테라 델리시오사를 뺐어요."
      actionLabel="되돌리기"
    />
  ),
});
```

`SnackbarProvider` 는 브라우저에 붙은 뒤에 `document.body` 로 포털을 열기 때문에, 서버에서 그리는 앱(Next.js 등)에서도 그대로 쓸 수 있습니다.
