## Installation

```npm
npx shadcn@latest add @kcn-seed/help-bubble
```

## Usage

For a bubble opened by pressing, compose `HelpBubbleRoot` and `HelpBubbleTrigger` with `HelpBubblePositioner` › `HelpBubbleContent` › `HelpBubbleArrow` (with `HelpBubbleArrowTip`) and `HelpBubbleBody` (with `HelpBubbleTitle` and `HelpBubbleDescription`). It doesn't take focus when it opens, so it can open together with the page via `defaultOpen`.

## Examples

### Tooltip

`HelpBubbleTooltipTrigger` wraps a single element and shows the bubble on hover or focus, with `title` and `description` as props. Wrap several in `HelpBubbleTooltipDelayGroup` so moving between them opens the next one without waiting.
