## Installation

```npm
npx shadcn@latest add @kcn-seed/command
```

## Usage

`Command` is a Base UI Autocomplete whose list is always open. Pass the data through `items` (flat, or groups of `{ value, items }`) and render it with a function child of `CommandList` — for groups, render `CommandGroup` with `CommandGroupLabel` and a `CommandCollection`. `CommandEmpty` shows when nothing matches. One item is always highlighted, and pressing Enter calls its `onClick`.

## Examples

### Dialog

`CommandDialog` puts the palette in a modal near the top of the screen. It closes on an outside click or Esc. This demo also toggles it with ⌘K / Ctrl+K.
