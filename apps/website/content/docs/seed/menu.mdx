## Installation

```npm
npx shadcn@latest add @kcn-seed/menu
```

## Usage

Positioning and `size` go on `MenuRoot`. Inside `MenuContent`, group items with `MenuGroup` — consecutive groups are separated by a divider, and `MenuGroupLabel` titles a group. `MenuItem` takes a `label`, optional `description`, and icons; use `tone="critical"` for destructive actions.

## Examples

### Groups and Radio Items

`MenuRadioGroup` with `MenuRadioItem` lets the user pick one option; the selected item shows a check, and the menu stays open so the change is visible right away.
