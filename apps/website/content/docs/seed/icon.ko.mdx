## 설치

```npm
npx shadcn@latest add @kcn-seed/icon
```

## 사용법

`Icon` 은 `svg` 로 준 요소(`<IconHeartLine />` 등)를 감싸는 요소 없이 그대로 그립니다. 크기와 색은 부모 부품이 `--icon-size` · `--icon-color` 로 정하고, `size` · `color` 를 주면 그 값이 이깁니다. `PrefixIcon` · `SuffixIcon`(`affix-icon`)은 `ActionButton` 같은 부품 안에서 글자 앞뒤에 놓는 아이콘으로, 크기 · 색 · 여백을 부모가 정합니다.
