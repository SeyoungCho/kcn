## 설치

```npm
npx shadcn@latest add @kcn-seed/side-navigation
```

## 사용법

접힘 상태는 `SideNavigationProvider` 가 쥐고, 그 안 어디서든(상단 줄의 버튼 등) `useSideNavigationContext()` 로 읽고 바꿀 수 있습니다. 화면 폭이 1280px 보다 좁아지면 저절로 접히고, 다시 넓어지면 펼쳐집니다. `SideNavigationRoot` 안에는 `SideNavigationHeader`(접기 버튼 `SideNavigationTrigger` 를 함께), 스크롤되는 `SideNavigationContent` 와 그 안의 `SideNavigationGroup`, 그리고 필요하면 `SideNavigationFooter` 를 놓습니다. 옆의 본문은 `SideNavigationInset` 에 넣습니다.

`items` 가 있는 줄은 하위 메뉴를 가집니다. 펼친 메뉴에서는 아래로 펼쳐지고, 접힌 메뉴에서는 Navigation Menu 로 옆에 뜹니다.

`SideNavigationTrigger` 의 이름은 기본이 `사이드바 열기` · `사이드바 닫기` 이고, `openLabel` · `closeLabel` 로 바꿀 수 있습니다.

## 예제

### 접힌 메뉴

접히면 아이콘만 남습니다. 줄에 마우스를 올리면 이름이 말풍선으로 보이고, 하위 메뉴가 있는 줄은 옆에 하위 메뉴를 띄웁니다.
