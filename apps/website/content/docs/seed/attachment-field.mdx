## Installation

```npm
npx shadcn@latest add @kcn-seed/attachment-field
```

## Usage

`AttachmentField` adds the label, description, and error message, and holds the entries. Put `AttachmentInput` (an 80×80 picker button with items beside it) or `AttachmentDropzone` (a drop area with items below it) inside.

The field never uploads anything. New files arrive in `onFileAccept` with an `updateFileEntryStatus(id, details)` helper — start the upload there and move each entry through `pending`, `uploading` (with an optional `progress` from 0 to 100), `success`, or `error`.

The built-in button and hint text are Korean; pass `labels` (`selectFile`, `dropFile`, `retry`, `removeFile`) to `AttachmentField` or `AttachmentDisplayField` to override them.
