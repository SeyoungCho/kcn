## Installation

```npm
npx shadcn@latest add @kcn-seed/floating-toolbar
```

## Usage

`FloatingToolbar` is rendered into `document.body` and centered over the page's `main` element (or the whole viewport when there is none), so tables and scroll containers don't clip it. Fill it with `FloatingToolbarLabel`, `FloatingToolbarSeparator`, and `FloatingToolbarButton`. Passing `onDismiss` adds a close button beside the toolbar and closes it on Escape. When the actions don't fit, the toolbar scrolls sideways — by wheel or by dragging with the mouse. The default `closeLabel` is Korean, so pass your own for other languages.
