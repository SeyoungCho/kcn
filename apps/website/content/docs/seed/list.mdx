## Installation

```npm
npx shadcn@latest add @kcn-seed/list
```

## Usage

`List` renders a `ul`. Pick the row that matches the interaction:

- `ListItem` — a static row; only controls placed in `suffix` are interactive.
- `ListButtonItem` — the whole row is a button (or a link with `render={<a href="…" />}`).
- `ListCheckItem` — the whole row is a checkbox. Wrap the list with `render={<fieldset />}` and show the state with `ListCheckmark`.
- `ListRadioItem` — the whole row is a radio. Wrap the list with `render={<ListRadioGroup … />}` and show the state with `ListRadiomark`.

Put `ListHeader` right above the list and `ListDivider` between rows. Interactive controls placed in `prefix` or `suffix` of a `ListButtonItem` need `position: relative` to sit above the row button.
