## Installation

```npm
npx shadcn@latest add @kcn-seed/tabs
```

## Usage

Compose `TabsRoot` > `TabsList` > `TabsTrigger`, with one `TabsContent` per trigger sharing its `value`. `triggerLayout` and `size` go on the root and apply to the list and every tab. Arrow keys select the focused tab right away.

## Examples

### Trigger Layout

`"fill"` splits the width evenly; `"hug"` sizes each tab to its text and lets the list scroll sideways.
