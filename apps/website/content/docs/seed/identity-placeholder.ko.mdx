## 설치

```npm
npx shadcn@latest add @kcn-seed/identity-placeholder
```

## 사용법

`IdentityPlaceholder` 는 부모의 크기를 다 채우므로, 크기와 모양은 부모가 정합니다. 보통 `Avatar` 의 `fallback` 으로 줍니다.
