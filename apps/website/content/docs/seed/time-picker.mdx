## Installation

```npm
npx shadcn@latest add @kcn-seed/time-picker
```

## Usage

The wheels show a 12-hour clock, but the value is always 24-hour `{ hour, minute }` with no separate AM/PM field. Turning the hour past 11 flips AM and PM.

## Examples

### Minute Step

`minuteStep` sets the minute interval (1, 5, 10, 15, or 30). Values off the interval snap to the nearest step.

<Preview
  registry="seed"

### Locale

`locale` sets the AM/PM labels, the number format, and the column order. Korean, English, and Japanese AM/PM labels are fixed so server and browser render the same text; pass `periodLabels` to use your own.
