## Installation

```npm
npx shadcn@latest add @kcn-seed/skeleton
```

## Usage

`width` and `height` take a dimension token (`"x12"`), `"full"`, a px number, or any CSS value. When a skeleton stands in for a line of text, set `height` to that text's line-height token, such as `"lineHeight.t4"`.
