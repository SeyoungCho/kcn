## 설치

```npm
npx shadcn@latest add @kcn-seed/tag-group
```

## 사용법

`TagGroupRoot` 는 안의 `TagGroupItem` 사이에 구분자를 넣습니다. 묶음에 준 `size` · `weight` · `tone` 은 모든 항목에 적용되고, 항목에 직접 주면 그 항목만 바뀝니다.
