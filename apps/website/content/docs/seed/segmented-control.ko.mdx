## 설치

```npm
npx shadcn@latest add @kcn-seed/segmented-control
```

## 사용법

`SegmentedControl` 은 라디오 묶음이고, `SegmentedControlItem` 하나가 칸 하나입니다. 묶음에는 `aria-label` 이나 `aria-labelledby` 로 읽는 이름을 주세요.
