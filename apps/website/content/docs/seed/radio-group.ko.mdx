## 설치

```npm
npx shadcn@latest add @kcn-seed/radio-group
```

## 사용법

`RadioGroup` 이 값을 들고 이름표 · 도움말 · 오류 메시지를 그려요. 안에 선택지마다 `RadioGroupItem` 을 하나씩 놓고, `tone` 과 `size` 는 항목마다 줘요.
