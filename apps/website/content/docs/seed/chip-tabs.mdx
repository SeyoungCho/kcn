## Installation

```npm
npx shadcn@latest add @kcn-seed/chip-tabs
```

## Usage

Compose `ChipTabsRoot` > `ChipTabsList` > `ChipTabsTrigger`, with one `ChipTabsContent` per trigger sharing its `value`. `variant` and `size` go on the root and apply to every chip. Arrow keys select the focused chip right away.
