## Installation

```npm
npx shadcn@latest add @kcn-seed/side-panel
```

## Usage

`SidePanelContent` draws the panel with an optional `title`, `description`, and close button; put content in `SidePanelBody` (it scrolls when long) and buttons in `SidePanelFooter`. Swiping toward the edge it came from closes it. There's no built-in action button — control `open` to close the panel from your own buttons.
