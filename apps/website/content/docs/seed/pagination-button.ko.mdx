## 설치

```npm
npx shadcn@latest add @kcn-seed/pagination-button
```

## 사용법

`children` 으로 아이콘 요소 하나를 주면 버튼이 크기와 색을 입힙니다. 아이콘만 있는 버튼이라 늘 `aria-label` 을 주세요.
