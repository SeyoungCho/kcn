## Installation

```npm
npx shadcn@latest add @kcn-seed/snackbar
```

## Usage

Wrap your app in `SnackbarProvider` once. Then call `create({ render: () => <Snackbar … /> })` from `useSnackbarAdapter()` to show one. Only one snackbar shows at a time: by default a new one replaces the current one (`strategy="immediate"`), and `"queued"` waits for it to finish. The timer pauses while the pointer is over the snackbar or it has keyboard focus.

```tsx
const snackbar = useSnackbarAdapter();

snackbar.create({
  render: () => <Snackbar message="Moved to trash." actionLabel="Undo" />,
});
```

`SnackbarProvider` portals into `document.body` while it renders, so in server-rendered apps (such as Next.js) mount it on the client only.
