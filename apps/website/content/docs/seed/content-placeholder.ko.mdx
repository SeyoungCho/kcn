## 설치

```npm
npx shadcn@latest add @kcn-seed/content-placeholder
```

## 사용법

`ContentPlaceholder` 는 부모의 크기를 다 채우므로, 이미지 틀이나 카드의 사진 자리 같은 부모로 크기를 정하세요. 그림은 판 높이의 절반이고 가장 넓어도 160px 입니다. 그림은 꾸밈이라, 이름이 필요하면 판에 `role="img"` 와 `aria-label` 을 주세요.
