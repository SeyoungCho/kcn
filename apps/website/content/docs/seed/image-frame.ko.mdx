## 설치

```npm
npx shadcn@latest add @kcn-seed/image-frame
```

## 사용법

`ImageFrame` 은 폭과 `ratio` 로 크기가 정해지고, 사진은 틀을 덮도록 잘립니다. 위에 얹을 것은 자식으로 `ImageFrameFloater` 안에 넣고, 개수는 `ImageFrameIndicator`, 흰 아이콘은 `ImageFrameIcon`, 좋아요 버튼은 `ImageFrameReactionButton` 을 씁니다.
