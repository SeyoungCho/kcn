## Installation

```npm
npx shadcn@latest add @kcn-seed/responsive-dialog
```

## Usage

From 768px up it renders a `Dialog`; at 767px and below it renders a `BottomSheet`. If the width crosses that line while it's open, it stays open and switches form. The parts mirror the dialog's: `ResponsiveDialogTrigger`, `ResponsiveDialogContent`, `ResponsiveDialogBody`, `ResponsiveDialogFooter`, and `ResponsiveDialogAction`, a button that closes it. Pass form-specific options through `dialogRootProps` and `bottomSheetRootProps`. The form follows the preview's own width, so resize the window to see both.
