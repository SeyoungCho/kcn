## 설치

```npm
npx shadcn@latest add @kcn-seed/side-panel
```

## 사용법

`SidePanelContent` 는 `title` · `description` · 닫기 버튼을 갖춘 패널을 그립니다. 내용은 `SidePanelBody`(길면 여기만 스크롤됩니다)에, 버튼은 `SidePanelFooter` 에 넣으세요. 들어온 쪽으로 끌면 닫힙니다. 닫히는 버튼 부품은 따로 없으니, 내 버튼에서 닫으려면 `open` 을 제어하세요.
